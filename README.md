## 怎么使用：无需安装，直接发给任意 AI

Taste Lab 本质上是一组可移植的 Markdown 提示词规范，不依赖专用运行时、插件或 Agent Skills 系统。即使你使用的 AI 不支持 Skill 安装，也可以直接使用：

1. 下载当前推荐版 [`SKILL.md`](skills/design-taste-frontend/SKILL.md)，或者选择下方任一历史版本的 Markdown 文件。
2. 在同一个对话中，把 Markdown 文件与你自己的产品需求、页面内容和技术限制一起发送给 AI。
3. 明确要求 AI 完整阅读文件，把它作为本次任务的执行规范，并直接按规范完成页面，而不是只总结文件。

可以直接复制下面这段话，与 Markdown 文件和你的需求一起发送：

```text
请完整阅读我附加的 Markdown 文件，并将它视为本次前端任务的设计、实现与验收规范。
请结合我接下来提供的实际需求执行；除非其中内容与我的明确要求冲突，否则严格遵守该文件中的流程、审美决策、交互和质量检查要求。
不要只总结或解释这份文件，请直接使用它完成任务，并在交付前自行检查结果。

我的具体需求：
（在这里填写你想制作的页面、功能、内容、技术栈和其他限制）
```

如果平台不支持上传 Markdown，也可以复制文件全文，粘贴到同一条消息或同一个对话中。历史版本适合复现对应阶段的风格；日常使用建议选择当前 V0.4。

## 可选：安装为 Agent Skill

安装不是使用本项目的前提。只有在支持 Agent Skills、并希望长期复用或通过名称调用时，才需要配置。支持安装器的环境可以运行：

```bash
npx skills add https://github.com/WangHexinyi/taste-lab --skill design-taste-frontend
```

也可以手动复制 [`skills/design-taste-frontend`](skills/design-taste-frontend) 到 Agent Skills 目录，并通过 `$design-taste-frontend` 显式调用。

## V0.0：实验起点

V0.0 原始目录中只有 [`TasteSkill.md`](archive/v0.0/TasteSkill.md)，没有 HTML 文件。它被保留为 prompt-only 起点，不把其他版本的成品冒充成它的效果。
