# SKILL.md - High-Fidelity Frontend Design System

A professional design system for creating stunning, production-ready frontend interfaces.

## 🚀 Quick Start

This repository contains:
- **SKILL.md**: Complete design system and workflow guidelines
- **examples/**: Real-world implementations showcasing best practices

## 📋 Core Philosophy

**Default to Excellence** - Every output must meet professional visual standards without requiring explicit triggers.

### Key Principles

1. **Visual Sophistication**: Deep understanding of spacing, typography, color theory, and motion
2. **Technical Precision**: Clean, semantic code with performance optimization
3. **User-Centric**: Accessibility-first approach with meaningful interactions
4. **Aesthetic Confidence**: Bold design choices backed by UX principles

## 🎨 Design System Highlights

### Typography
- Primary: Geist Sans (or system-ui)
- Secondary: JetBrains Mono for code/data
- Modular scale with proper hierarchy

### Color
- Dark mode default (#0a0a0a bg, #fafafa text)
- Brand-derived accent colors
- Subtle gradients for depth

### Images (CRITICAL)
- ✅ High-quality product photography
- ✅ Realistic imagery matching content
- ❌ No简笔画, abstract SVGs, or placeholders

### Motion
- Default intensity: 7/10
- Tech/Hardware context: Auto-escalate to 8-9/10
- Premium easing: `cubic-bezier(0.16, 1, 0.3, 1)`
