# Security policy

## Supported version

Security fixes target the current Prompt Lab release, the current Agent Lab package and the GitHub Pages gallery. Historical snapshots under `archive/` and versioned Agent directories are retained for provenance and may not receive backports.

## Reporting a vulnerability

Please do not open a public Issue for a suspected secret exposure, malicious demo payload, dependency compromise or other exploitable behavior.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/WangHexinyi/taste-lab/security/advisories/new

Include the affected path, reproduction steps, impact and any safe mitigation you have tested. You should receive an acknowledgement within seven days.
