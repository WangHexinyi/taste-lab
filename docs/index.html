02 / AGENT LAB

把完整能力包
安装进 Agent。

这一条路线包含 SKILL.md、分层 references、可执行脚本与自测样例。下载压缩包、完整解压，再把 taste-frontend 文件夹放进 Agent 的 Skill 目录。

这是通用 Agent Skill。不同宿主的 Skills 目录、frontmatter 白名单、Node 和浏览器能力可能不同，请按宿主的官方说明安装。
