十三轮标定手记：从噪音到秩序

R01 BASELINE POOL 建立 77 组盲测样本对，基线主观方差 σ² = 0.482，直觉呈现高度分散。 σ² 0.482

CHAPTER 03 / AESTHETIC LAWS EXHIBIT
SIX CORE AXIOMS

直觉提炼为定律：
量化后的六条不可逆法则

AXIOM 01 · PRAGMATISM CORE
"黑猫白猫，能抓到耗子就是好猫。"

实用主义是高级审美的底色。解法如果不能降低用户的认知负荷与视觉摩擦，再精巧的几何构成也只是孤芳自赏的无效自嗨。

AXIOM 02 · DEPTH OF FIELD SPATIAL
"基本功防灾难，景深拿三分。"

排版、对齐、字阶与对比度是 0 到 60 分的防御工事；而光影微调、多层视差与空间景深，才是让作品从及格跨越到卓越的关键。

AXIOM 03 · CONSENSUS DIVERGENCE COGNITIVE
"行业共识 ≠ 用户共识。"

设计社区追捧的浮夸炫技往往是真实场景的认知灾难。永远不要用设计圈的内卷惯性，去替代真实用户对清晰、安静与秩序的直觉渴望。

AXIOM 04 · DENSE SILENCE REDUCTION
"克制不是单调，而是高密度的静默。"

留白是全站成本最高的布局决策。它不是空无一物，而是将巨大的信息密度压缩进极度严谨的比例尺中，释放持久的凝视张力。

AXIOM 05 · MATERIAL TRUTH TEXTURE
"真实矿物灰终将战胜塑料拟态。"

告别悬浮的劣质毛玻璃与刺眼霓虹。让颜色沉淀进低饱和的陶土、灰鼠尾草与深焙黑曜石中，让像素拥有岩石与纸张的物理重量。

AXIOM 06 · TRANSCENDENCE METHOD
"量化直觉，是为了超越直觉。"

将品味拆解为数学权重与梯度收敛，绝非为了抹杀灵感，而是为了构建一套可被反复复现、可被持续进化的审美工程系统。

《我为什么不再用紫色渐变》
